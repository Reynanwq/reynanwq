## ⭐ Destaques

### 🔐 SIAL — Sistema Integrado de Acesso ao Laboratório
Controle de acesso ao LabIC (Instituto de Computação – UFBA). Liderei a arquitetura e o desenvolvimento: back-end em **Spring Boot** com API REST, autenticação/autorização via **JWT** e **MySQL**, e app mobile em **Flutter** publicado na **Google Play Store**. Em produção desde 04/2025, com **+340 usuários ativos**.

### 📚 Capacitic (SIAC)
Plataforma web de capacitação em TIC para estudantes do ensino médio e pessoas em situação de vulnerabilidade social, com trilhas de aprendizado focadas em acessibilidade. **React + Spring Boot + MySQL**, em time ágil (Scrum/Kanban).

### 🩺 MEDIC — LaSiD/UFBA
Rede de sensores vestíveis (WBAN) para monitoramento de saúde em tempo real. Aplicações web e mobile com **Spring Boot, React e React Native**, e transmissão de dados de biossensores entre **Raspberry Pi** e servidores via **MQTT**.
